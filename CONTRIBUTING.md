# Contributing

If you've found a bug or want to help develop Euterpe, please contact us through
our [contact page](https://euterpe-org.com/docs/community/contact).

## Issues

Most of Euterpe isn't in public repositories, so most bugs can't be tracked on
GitHub. Please only open an issue here if it's about this repository. For
anything else, use the contact page.

## Pull requests

Our products depend on each other a lot. A change to one usually needs matching
changes elsewhere, often in code that isn't public. For that reason we rarely
merge pull requests we haven't discussed beforehand, even good ones.

If you want to work on something, contact us first and tell us what you're
thinking of doing. Then we can talk it over.
